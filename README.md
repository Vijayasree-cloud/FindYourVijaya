# 🚀 Find Your Vijayam

An interactive **full-stack career discovery and simulation platform** that helps users explore career paths and make **data-driven decisions** to achieve their *Vijayam (success)*.

---

## 🚨 Problem Statement

Choosing the right career path is challenging due to:

* ❌ Lack of proper guidance and mentorship
* ❌ No visibility into future career growth and opportunities
* ❌ Confusion between multiple career options
* ❌ Decisions based on guesswork instead of data

---

## 💡 Solution

**Find Your Vijayam** solves this by providing:

* 🎯 Career path exploration
* 📊 Data-driven insights (growth, demand, trends)
* 🤖 Interactive and engaging UI experience
* 🧠 Backend-powered data handling and scalability

It transforms decision-making from **confusion → clarity → success**.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash id="o9k2dm"
git clone https://github.com/Vijayasree-cloud/FindYourVijaya.git
cd FindYourVijaya
```

---

### 2. Install dependencies

#### Frontend

```bash id="u2m8hx"
cd frontend
npm install
npm run dev
```

#### Backend

```bash id="n4v6jq"
cd backend
npm install
npm start
```

---

### 3. Environment Variables

Create a `.env` file in backend:

```env id="v8t3cw"
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
PORT=5000
```

---

* `GET /api/careers` → Fetch career data
